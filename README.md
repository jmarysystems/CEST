# CEST

Consulta e manutenção da tabela CEST (Código Especificador da Substituição
Tributária — Convênio ICMS 142/18), no mesmo padrão dos demais sistemas.

## Dados

Tabela `cest` no Supabase, carregada do arquivo `tb16643.txt`
(versão 18): 2.185 registros, 1.049 códigos distintos, com vigência.

## Permissões

Módulo `cest` do Controle de Acesso.

## Rodar localmente

```bash
python -m http.server 5500
```
